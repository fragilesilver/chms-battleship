# CHMS Battleship Royale (Phase 1)

Upload everything in this folder to the root of your GitHub Pages repo, keeping the `js/` and `css/` folders.

- Students open: `https://<your-username>.github.io/chms-battleship/`
- Teacher opens: `https://<your-username>.github.io/chms-battleship/teacher.html`

Keep the teacher tab open during a battle. It hands out the free shots on a timer.
